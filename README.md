🌟 Bagyamithram (ഭാഗ്യമിത്രം) v1.0.0
Welcome to the official release of Bagyamithram, an Android application designed for Kerala State Lottery searches, daily picks, and result scanning tools.

✨ Key Features:
🔍 Fast Result Search: Quick and easy lookup for Kerala State Lottery results.
📅 Daily Picks: Access daily numbers and updates.
📱 User-Friendly UI: Built natively with React Native and Expo for a smooth experience.
📥 How to Install:
Download the Bagyamithram.apk file attached below.
Tap on the downloaded file to install it on your Android device (ensure "Install from unknown sources" is enabled if prompted).
Open the app and enjoy!
